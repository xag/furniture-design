# Hawk Ridge Systems: How to isolate components in SOLIDWORKS assemblies

https://hawkridgesys.com/blog/how-to-isolate-components-in-solidworks-assemblies

(The SOLIDWORKS help page for the Isolate dialog, https://help.solidworks.com/2021/English/SolidWorks/sldworks/HIDD_COMP_ISOLATE_DLG.htm, returned a 502 and an empty shell; this is a SOLIDWORKS reseller's account of the same command.)

> Isolate has the same effect as hiding all other components in the assembly by default

> you can adjust the display settings of the other components to Wireframe or Transparent if desired.

> While isolated, the rest of the assembly can be shown as wireframe, transparent, or hidden.
