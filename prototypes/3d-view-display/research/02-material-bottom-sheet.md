# Material Components for Android: Bottom sheets

https://github.com/material-components/material-components-android/blob/master/docs/components/BottomSheet.md

(m3.material.io renders its text in script and returned nothing to a fetch; this is Material's own component documentation.)

Standard bottom sheets:

> co-exist with the screen's main UI region

Modal bottom sheets:

> present a set of choices while blocking interaction with the rest of the screen

Drag handle:

> The handle also supports tapping to cycle through expanded and collapsed states as well as double tapping to hide.

> `BottomSheetDragHandleView` has a default min width and height of 48dp to conform to the minimum touch target requirement.
