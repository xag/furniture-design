# Autodesk Revit 2023 Help: About Temporary Dimensions

https://help.autodesk.com/cloudhelp/2023/ENU/Revit-DocumentPresent/files/GUID-74FFB00B-FB29-44B7-8FEA-613DBE010AD4.htm

How a building-design tool shows an element's own dimensions on demand: for the element placed or selected, not for every element at once.

> After you place the element, Revit displays the temporary dimensions.

> When you place another element, the temporary dimensions for the previous element no longer display.

> To view the temporary dimensions of an element, click Modify and select the element.

> Temporary dimensions snap to the nearest perpendicular element and adjust by a defined value.
