# Unity Editor Human Interface Guidelines: Hiding vs disabling controls

https://unitytech.github.io/unityeditor-hig/best-practices/hiding_vs_disabling_controls

> Hide input controls (e.g., Text Fields, Color Fields or Popups) when the value shown is currently irrelevant and not used.

> Disable the control when the value shown is still relevant, but it is uneditable.

> always place the hidden control somewhere below the control that triggers the hiding.

> Ideally, the hidden control should be on the next line.
