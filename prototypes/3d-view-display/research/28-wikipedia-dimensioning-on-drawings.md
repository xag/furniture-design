# Wikipedia: Dimensioning on drawings

https://en.wikipedia.org/wiki/Dimensioning_on_drawings

> Dimension lines must not cross anything.

> Detail dimensions should be closest to the drawing, followed by general dimensions.

On repeated elements (one dimension line with the count):

> a single dimension line is drawn, on which the number of times the value is repeated, the multiplicative sign X, the repeated dimension, the sign = and the sum

On dimensions from one origin (parallel dimensioning, which gives positions, as against a chain, which gives the gaps between neighbours):

> all dimensions start from the same origin, the longest face or edge, parallel to the drawing.
